# Rocket Charts

Internal diagramming tool for Rocket Partners.

Built on [FossFLOW](https://github.com/stan-smith/FossFLOW), which is based on the [Isoflow](https://github.com/markmanx/isoflow) library.

## Quick Start

```bash
# Install dependencies
npm install

# Build the library (required first time)
npm run build:lib

# Start development server
npm run dev
```
